Wire up the AgentForm in frontend/components/AgentForm.tsx to actually POST to the backend API.

For now, convert each tool string to { type: "function", function: { name: toolName, description: toolName, parameters: { type: "object", properties: {} } } }.

2. The guard_config in the form has fields like pii_redaction, toxicity_filter etc. The backend expects inspector_enabled, bodyguard_enabled, pii_detection, max_tokens_per_response. Map: inspector_enabled = toxicity_filter, bodyguard_enabled = true if any guard enabled, pii_detection = pii_redaction, max_tokens_per_response = max_tokens_per_response.

3. The memory_config in the form has fields like type, max_history, summarization, vector_search. The backend expects enabled, memory_type, max_memories. Map: enabled = enabled, memory_type = type, max_memories = max_history.

4. Import and use fetch to POST to /api/agents with the transformed data.
   API URL from process.env.NEXT_PUBLIC_API_URL or http://localhost:8000.
   For now, include a hardcoded workspace_id in the token claims or skip auth header.

5. On success, show a success message and call onCancel to close the form.
6. On error, show the error message in the form.
